**Workflow bundle.** When the worktree is a workflow bundle (it has `workflows/` and `steps/` at its root), run `lc workflow check --dir <worktree>` before committing and fix what it reports. Never use plain `lc workflow check` for this: it reads the installed pinned bundle, not your edit. If `lc workflow check --dir` refuses because the bundle's `requires-engine` is above the installed `lc --version`, park the step with `lc set <step> --state waiting --needs "engine <required> needed, <installed> installed; upgrade the engine and set this step ready" --reason "<what the check reported>"`, naming both versions; the driver upgrades the engine and sets it ready. Never lower `requires-engine` to make the check pass.
