**A `ci-failed` rework.** When `inputs.previous` is a `watch-ci` step closed `ci-failed`, its `report` names the failing job and test ids. If the failing test is outside this branch's diff and green when you run it locally on the same sha, closing `done` would only re-trigger the same result: park instead, `lc set STEP --state waiting --needs "<test id>, <local evidence>" --reason "<what happened that led here>"`. A human re-runs the failed job once (`gh run rerun <run-id> --failed`) and closes the parked step `done`, so `poll-ci` and `watch-ci` read the fresh result. Otherwise fix the failure like any other rework.
