- Findings, before either outcome below calls `lc done`: write every defect this review reached to a JSON array file and attach it with `lc attach STEP review-findings --file <path>` (add `--replace` if one is already attached). Each element has exactly the keys `severity`, `kind`, `file`, `line` and `summary`: `severity`, `kind` and `summary` are non-empty strings and `summary` is one line; `file` is a path or `null`; `line` is a positive integer or `null`, and `null` whenever `file` is `null`. Attach on a pass as well as a reject; a clean pass attaches `[]`, which records that the review ran and found nothing.
