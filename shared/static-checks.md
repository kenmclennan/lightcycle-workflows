**Before handing off.** Run every lint, format and typecheck command the repository defines, on the whole repository with no scoping, and run the tests for what the change touches. The repository's full test gate is not required when a workflow runs on pull requests, because CI is then the full check; where the repository has no CI workflow that runs on pull requests, run the full test gate before handing off instead. Read each command from the repository's own `CLAUDE.md`, README, build file or CI workflow, and run it through the repository's own scripts.
