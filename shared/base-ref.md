**Resolve the base branch.** Right after `git fetch origin`, run `git remote set-head origin --auto`, then let BASE_REF be the output of `git symbolic-ref --short refs/remotes/origin/HEAD` (it prints `origin/<the repo's default branch>`). If either command fails, park rather than assume a branch name: `lc set STEP --state waiting --needs "the default branch of origin could not be resolved: <the git output>" --reason "<what the resolution found>"`, then EXIT. BASE_REF is used throughout this step, including in text before this paragraph. Wherever this step diffs, merges, counts behind or rebases against the base, it uses BASE_REF, never a literal branch name.
