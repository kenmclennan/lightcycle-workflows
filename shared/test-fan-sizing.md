**Sizing the test fan.** The pool exports its worker cap as `LC_MAX_AGENTS`, and the repo's own gate script sizes its parallelism from it. Run the gate through that script and do not do the arithmetic yourself - no reading the config file, no core-count division. If the repo's gate does not read `LC_MAX_AGENTS`, keep running the full gate rather than narrowing it, and size its timeout generously since an unsized run may contend.
